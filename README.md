# SandboxTesting

A sandbox for prototyping game ideas — quick, disposable experiments rather than a single production project.

## Purpose

This repo is a playground for testing game concepts, mechanics, and technical spikes. Individual prototypes may live in subdirectories and use different stacks as needed.

## Status

🚧 Active prototype: [`prototypes/wow-sandbox/`](prototypes/wow-sandbox/) — Unity + `wow.export` pipeline for pulling World of Warcraft models into a sandbox scene (personal/non-commercial use). See [`docs/wow-model-research.md`](docs/wow-model-research.md) for the tooling/engine research behind this choice.
