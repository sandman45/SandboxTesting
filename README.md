# SandboxTesting

A sandbox for prototyping game ideas — quick, disposable experiments rather than a single production project.

## Purpose

This repo is a playground for testing game concepts, mechanics, and technical spikes. Individual prototypes may live in subdirectories and use different stacks as needed.

## Status

🚧 Active prototype: [`prototypes/wow-sandbox/`](prototypes/wow-sandbox/) — **Tidegrave Isle**, a single-player survival and story game with a D&D ruleset, built in Unity from World of Warcraft models via `wow.export` (personal/non-commercial use). See [`docs/wow-model-research.md`](docs/wow-model-research.md) for the tooling/engine research behind this choice.
